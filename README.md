# Приоритизация алертов SIEM: машинное обучение и LLM

Прототип к выпускной квалификационной работе. Тандем: модель машинного обучения (XGBoost) отбирает подозрительные
алерты SIEM, большая языковая модель (LLM) объясняет отобранные алерты аналитику — что произошло, почему подозрительно,
что делать.

Данные — открытый набор [AIT-ADS](https://github.com/ait-aecid/alert-data-set) (алерты Wazuh, Suricata и AMiner
восьми учебных сетей). В репозиторий входит только код; данные кладутся в `data/raw/ait_ads/`.

## Шаги

| Шаг | Файл | Что делает |
|---|---|---|
| 1 | `simple/1_data.py` | собирает алерты, ставит метки по интервалам атак, делит каждую сеть на раннюю и позднюю часть, сети — на группы A и B |
| 2 | `simple/2_samples.py` | две оценочные выборки по 200 алертов |
| 3 | `simple/3_ml.py` | пять ML-моделей (XGBoost, LightGBM, RandomForest, логистическая регрессия, линейный SVM) на одинаковых признаках, проверка на сетях, которых модель не видела; выбор итоговой; проверка признаков |
| 4 | `simple/4_tandem.py` | итоговая модель отбирает алерты, LLM (Qwen 3.5 4B, GPT-6-sol, gpt-oss-120b, Claude) объясняет отобранные |
| 5 | `simple/5_eval.py` | итоговые таблицы |
| 6 | `simple/6_dashboard.py` | дашборд одним HTML-файлом |

Подробности — в `simple/README.md`.

## Запуск

```
py -3.13 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
powershell -ExecutionPolicy Bypass -File simple\run_all.ps1
```

Запросы к облачным LLM платные и выполняются только явно: `python simple\4_tandem.py --ask "gpt-oss-120b"`
(ключ — в переменной окружения `POLZA_API_KEY`, в код не записывается).

## Основные результаты (выборка 1: 200 алертов, 87 атак)

| | F1 | Найдено / ложных |
|---|---|---|
| XGBoost (итоговая ML) | 0,864 | 73 / 9 |
| Лучшая LLM в одиночку (Claude) | 0,743 | 55 / 6 |
| «Всё — атака» | 0,606 | 87 / 113 |

На всём тестовом потоке (156 592 алерта) XGBoost замечает 35 из 35 эпизодов атак и сокращает поток аналитику
с 867 до 67 алертов в час.
